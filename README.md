# Ripple ice

Interactive recycle / landfill journey sketch (p5.js), with optional webcam hand control.

**Gestures**
- Cursor = midpoint between thumb tip and index tip
- Pinch = pick / tap
- Pinch + hold = drag
- Open = drop / release
- Hold still ~1s = backup tap

## Local

```bash
python3 -m http.server 8767
```

Open http://127.0.0.1:8767/
